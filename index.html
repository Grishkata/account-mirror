Account Mirror

A private Windows desktop tool that copies trades from one cTrader account to the owner's other cTrader accounts.

Account Mirror is for personal use by its developer. It is not sold, distributed or offered as a service, and it does not provide signals, investment advice or account management for anyone else.

What it does

The owner chooses one of their cTrader accounts as the main account and their other accounts as followers. Whatever happens on the main account is copied onto the followers:

  • new market positions
  • pending orders, including amendments and cancellations
  • partial closes, in proportion
  • Stop Loss and Take Profit changes
  • full closes

Volume on each follower can be the same as the main, a multiple of it, or a fixed lot size.

How it connects

  • It uses the official cTrader Open API from Spotware.
  • The account owner signs in through cTrader's own OAuth login page and chooses which accounts to connect.
  • It only connects to accounts that belong to the same cTrader ID. It never accesses anyone else's accounts.
  • It runs locally on Windows. The OAuth redirect goes to http://localhost:8080/callback on the same computer.

Safety rules

  • Copying is off by default. The app first shows what it would do, and copying has to be switched on by hand.
  • It asks for confirmation before copying onto a live account.
  • It never trades on the main account.
  • It only changes orders and positions it created itself, each marked with the label AccountMirror. Nothing else on a follower account is touched.
  • If the main account can't be read, for example because the connection drops, it does nothing. It doesn't close copies.

Privacy and data

  • There are no servers. All data stays on the owner's computer.
  • The Open API Client Secret and access tokens are stored encrypted with Windows DPAPI, readable only by the owner's Windows user.
  • No account data, trades or credentials are sent anywhere except to cTrader's Open API.
